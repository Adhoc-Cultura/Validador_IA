# Validador de Governança d'IA · Adhoc

Eina interna d'Adhoc per validar i certificar l'ús de la intel·ligència artificial en els projectes culturals de l'organització.

Combina dues dimensions:

- **Escala interna d'intensitat** (Nivells 1–4), segons el grau d'ús d'IA.
- **Classificació de risc de la Llei d'IA** (Reglament UE 2024/1689): risc inacceptable, alt risc, transparència i risc mínim.

A partir de les respostes genera automàticament el disclaimer de transparència, l'etiqueta de transparència quan escau i un segell de certificació descarregable en PNG.

## Ús

És un únic fitxer HTML autònom, sense dependències externes. Es pot:

- Obrir directament al navegador (`index.html`).
- Publicar via GitHub Pages (vegeu més avall).

## Publicació amb GitHub Pages

El repositori està preparat perquè `index.html` es publiqui automàticament. Un cop activades les Pages a la configuració del repositori, l'eina queda accessible a través de l'enllaç públic que proporciona GitHub.

## Estructura

```
index.html    → l'aplicació completa (autònoma)
README.md     → aquest document
LICENSE       → llicència d'ús
```

## Avís

Aquesta eina és un suport de governança interna. No substitueix la revisió humana obligatòria establerta a la normativa d'Adhoc ni l'assessorament jurídic. La Llei d'IA i les seves guies d'aplicació poden actualitzar-se; reviseu-ne la versió vigent.
